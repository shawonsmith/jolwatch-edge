# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 2.0.x | :white_check_mark: |
| < 2.0 | :x: |

## Reporting a Vulnerability

As an offline-first client application, JolWatch Edge processes data locally within the browser or edge runtime and does not transmit telemetry to external servers.

If you discover a security vulnerability (such as a DOM injection or localStorage parsing flaw), please report it responsibly by contacting:
- **Email:** `smithitcompany@gmail.com`
- Or open a private security advisory on GitHub.

Please include:
1. Steps to reproduce the issue.
2. The affected browser or runtime environment.
3. Potential impact.

We will review reports within 48 hours and release fixes promptly.
