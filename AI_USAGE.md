# AI Assistance Disclosure

In the spirit of scientific transparency and open-source integrity, this document outlines how Artificial Intelligence tools were utilized in the development of **JolWatch Edge**:

1. **Architecture & Logic Formulation:** The core water-balance methodology, the Essential Reserve Clock concept, and the decision thresholds were conceptualized and designed by Shawon Khan.
2. **Code Implementation & Refactoring:** Large Language Models (AI coding assistants) were used for:
   - Writing boilerplate DOM manipulation and internationalization tables.
   - Refactoring single-file prototype code into modular ECMAScript/CommonJS files.
   - Generating expanded boundary test cases for the Node.js test suite.
   - Formatting responsive CSS styles and documentation structures.
3. **Verification & Auditing:** All logic, mathematical formulas, and deterministic test executions were verified and executed locally by the developer.

This project remains an open-source research and engineering effort, and we welcome independent peer review, empirical validation, and code contributions.
